# Workspace Office Agents (`workspace/`)

Direktori ini adalah ruang kerja berpasir (*sandbox*) tempat ke-10 agen AI membaca dan menulis file proyek.

## Proyek Utama yang Dilacak Git

- [`office-next/`](./office-next/README.md) — Aplikasi **Ruang Kantor Virtual Isometrik 2.5D** yang dibangun dan dikembangkan langsung oleh tim 10 agen AI. Semua perubahan di dalam `workspace/office-next/` otomatis dipindai keamanannya oleh `Satria` / `GitService` dan di-commit serta di-push ke GitHub saat lulus review `Laras`.
